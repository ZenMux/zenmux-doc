# 订阅制套餐

ZenMux **Builder Plan** 为个人开发者提供固定月费、可预测的 AI 模型调用方案。一次订阅即可调度全球顶尖模型，让你专注编程与创作，无需担心每次 API 调用的费用。

## 套餐总览

Builder Plan 提供四档套餐，核心差异体现在**配额规模**与**可用模型范围**上。

<img src="https://static.zenmux.ai/public/images/doc/02-plan-cards.png" alt="ZenMux Builder Plan 四档套餐对比" >

| 套餐       | 月费     | 5 小时配额  | 模型范围                          | 赠送窗口重置 | API 调用     |
| ---------- | -------- | ----------- | --------------------------------- | ------------ | ------------ |
| **Free**   | $0       | 5 Flows     | 基础模型                          | —            | ❌ 仅 Studio Chat |
| **Starter**| $20/月   | 50 Flows    | 基础模型 + **限时开放**的旗舰模型 | 4 次/月      | ✅            |
| **Max**    | $100/月  | 300 Flows   | 基础模型 + 高级模型               | 3 次/月      | ✅            |
| **Ultra**  | $200/月  | 800 Flows   | 全量模型                          | 2 次/月      | ✅            |

::: warning Free 套餐不支持 API 调用
Free 套餐仅可在 **[Studio Chat](https://zenmux.ai/chat)** 网页端体验（约 5 次对话 / 5 小时），**不提供 API Request 能力**。如需在 Claude Code、Cursor、CodeX 等工具中通过 API Key 调用模型，请至少选择 **Starter** 套餐。
:::

::: info 名额限制
定价页顶部会显示 **SPOTS REMAINING（剩余名额）**。Builder Plan 目前采用限量发放，名额售罄后需等待下一批开放。
:::

## 各套餐详解

以下说明各套餐的定位与模型范围。**具体模型清单请通过对应卡片的 View 按钮查看**，本节不罗列模型名称。

### Free — 免费体验 {#free}

面向首次了解 ZenMux 的用户，可零成本体验平台的 AI 能力。

- **配额** — 5 Flows / 5 小时（约 5 次对话）
- **模型范围** — 基础模型
- **使用方式** — **仅限 [Studio Chat](https://zenmux.ai/chat) 网页端，不支持 API 调用**

### Starter — 日常首选 {#starter}

日常 Vibe Working 的主力方案，适合产品经理、市场、运营及轻量开发场景。

- **配额** — 50 Flows / 5 小时
- **模型范围** — 基础模型 + **限时轮换开放**的旗舰模型
- **专属权益** — Studio Chat + API 调用、每月 4 次赠送窗口重置、优先技术支持

::: warning 限时开放的模型会轮换
Starter 的旗舰模型清单采用**限时轮换**机制，会周期性更新。订阅前请先点击卡片中的 **View**，确认你依赖的模型当前是否在列；若该模型对你是刚需，建议选择 Max 或 Ultra。
:::

### Max — 高强度开发 {#max-high-intensity-development}

高性价比方案，适合刚开启 Vibe Coding 之旅的开发者。

- **配额** — 300 Flows / 5 小时（Starter 的 6 倍）
- **模型范围** — 基础模型 + 高级模型，覆盖绝大多数主流旗舰模型
- **专属权益** — 每月 3 次赠送窗口重置、新功能优先体验，并包含 Starter 的全部权益

### Ultra — 专业级旗舰 {#ultra-professional-flagship}

为高强度 Vibe Coding 与专业级开发打造。

- **配额** — 800 Flows / 5 小时（Starter 的 16 倍）
- **模型范围** — 全量模型
- **专属权益** — 每月 2 次赠送窗口重置、新功能优先体验，并包含 Max 的全部权益

::: info Max 与 Ultra 该怎么选?
Max 与 Ultra 当前覆盖的模型清单高度一致，两者核心差异在于**配额规模**（800 vs 300 Flows / 5h），而非模型种类。

- 若瓶颈是**用量**（经常触及 5 小时限额）→ 选择 Ultra
- 若瓶颈只是**模型种类** → Max 通常已经足够

最终请以定价页 **View** 弹窗的实际清单为准。
:::

## 什么是 Flows?

**Flow** 是 ZenMux 订阅制的复合计费单位，综合了 token 消耗量与 API 调用开销。

你可以把它理解为一种**货币**：就像不同商品在美元中有不同价格一样，不同 AI 模型每次请求消耗的 Flows 数量也不同。与按量付费的 Credits（固定 1 Credit = 1 USD）不同，**Flow 的 USD 等价价值是浮动的**，它反映了 API 用量背后的真实美元价值。

::: details 为什么使用 Flows 而不是直接用美元计价?
Flows 帮助平台平衡 token 负载，在保证服务质量稳定的前提下，让订阅制在长期可持续运营。
:::

### Flow/USD 实时汇率

<img src="https://static.zenmux.ai/public/images/doc/06-flow-usd-rate.png" alt="Flow/USD 实时汇率与历史走势" >

定价页提供**汇率换算器**与 **1 周 / 1 月 / 1 年**的历史走势图。截至 2026-08-04，汇率锚定在 **1 Flow ≈ $0.03283**（约 30 Flows = $1）。

::: warning 汇率会周期性调整
该汇率可能根据市场状况与模型定价变化进行调整，**上述数值仅为截图时刻的快照**。最新汇率始终在 [定价页](https://zenmux.ai/pricing/subscription) 实时公布。
:::

::: danger 滥用政策
对于违反 Builder Plan 服务条款的账号（如自动化滥用、资源囤积、多账号池化、未授权转售、共享账号等），其有效 Flow 价值将被**降低至标准费率以下**，即每个 Flow 的 USD 等价价值会减少。请合理使用你的订阅。
:::

### 套餐配额对比

<img src="https://static.zenmux.ai/public/images/doc/07-plan-comparison-table.png" alt="套餐配额对比：5 小时 / 每周 / 每月最大 Flows 及等价 USD 价值" >

上表为 **2026-08-04 的数据快照**，用于理解各档位的量级关系。

- **等价 USD 价值（Worth）** — 该套餐每月包含的**理论最大 API 价值**，按等效的按量付费价格折算。
- **价值杠杆** — 等价 USD 价值 ÷ 套餐月费，表示相比订阅费用你能获得多少倍的 API 价值。

::: tip 以定价页为准
上述 Flows 与 USD 数值均为**动态计算**结果，会随 Flow 汇率浮动。请以 [定价页](https://zenmux.ai/pricing/subscription) 实时显示的数据为准。
:::

::: tip Insider 会员的 Flow 价值加成
标准 Flow 价值适用于所有普通订阅用户。对于保持**活跃、连续订阅**（不中断）的早期 **Insider 会员**，每个 Flow 拥有更高的 USD 等价价值作为忠诚度奖励——同样消耗一个 Flow，你能获得更多价值。
:::

### 速率与窗口机制

| 项目         | 规则                              |
| ------------ | --------------------------------- |
| **速率限制** | 10–15 RPM（每分钟请求数）         |
| **配额窗口** | 滚动 5 小时窗口，自动刷新         |
| **周限额**   | 滚动 7 天窗口重置                 |

两个窗口均采用**滚动机制**：从你发出第一个请求开始计时，5 小时 / 7 天后自动重置。可在 [订阅管理页面](https://zenmux.ai/platform/subscription) 实时查看剩余配额与重置时间。

### 窗口重置次数

每个计费周期内，订阅用户拥有一定次数的**5 小时窗口重置**机会。当 5 小时配额即将用尽时，可手动重置窗口立即恢复配额，无需等待自然滚动重置。

<img src="https://cdn.marmot-cloud.com/storage/zenmux/2026/06/11/ahFja9m/20260611202440.jpg" alt="窗口重置功能示意" >

| 套餐        | 每月赠送重置次数 |
| ----------- | ---------------- |
| **Starter** | 4 次             |
| **Max**     | 3 次             |
| **Ultra**   | 2 次             |

::: tip 使用方式
在 [订阅管理页面](https://zenmux.ai/platform/subscription) 可查看剩余重置次数，点击「重置窗口」即可立即刷新 5 小时配额。也可开启 **自动重置**——配额用尽时系统自动消耗一次重置机会刷新窗口，无需手动操作。

重置次数按订阅周期计算（例如 6 月 3 日至 7 月 3 日），**过期不累计**。各套餐次数可能随运营策略调整，请以订阅管理页面实际显示为准。
:::

## Extra Usage - 超额自动切换

开启后，当订阅配额达到 5 小时或周限额时，自动切换至指定的按量付费 API Key 以保证不中断使用；配额恢复后自动切回订阅 Key。

### 核心优势

- **无缝切换** — 配额用尽时自动切换到按量付费，无需手动更换 API Key
- **不中断工作流** — 不影响你的开发、编程或对话流程
- **自动恢复** — 订阅配额恢复后自动切回订阅制计费
- **灵活可控** — 可随时启用或禁用

### 设置步骤

访问 [订阅管理页面](https://zenmux.ai/platform/subscription)，按以下步骤配置：

**步骤 1：启用 Extra Usage**

找到 **Extra Usage** 部分，点击右侧开关启用。

<img src="https://cdn.marmot-cloud.com/storage/zenmux/2026/02/03/8Ed42do/extra-1.png" alt="启用 Extra Usage" >

**步骤 2：选择按量付费 API Key**

在弹出的 **Select a Key** 对话框中：

- 从下拉列表选择一个现有的按量付费 API Key
- 或点击 **Create new key** 创建新的按量付费 API Key

<img src="https://cdn.marmot-cloud.com/storage/zenmux/2026/02/03/iJZufsS/extra-2.png" alt="选择 API Key" >

选择完成后点击 **Select** 确认。

**步骤 3：配置完成**

启用成功后页面会显示所选 Key 的详细信息，包括名称与密钥、启用状态、创建时间与最后使用时间、当前已使用金额，以及重新选择其他 Key 的操作入口。

<img src="https://cdn.marmot-cloud.com/storage/zenmux/2026/02/03/7ivqY3m/extra-3.png" alt="Extra Usage 已启用" >

### 工作原理

1. **正常使用** — 优先消耗订阅制配额（Flows）
2. **配额用尽** — 5 小时或周窗口达到上限时，自动切换到指定的按量付费 API Key
3. **按量计费** — 此期间的调用从账户余额中扣费
4. **自动恢复** — 订阅配额窗口重置后，自动切回订阅制计费

::: warning 计费提醒
启用 Extra Usage 后，订阅配额用尽时会自动从按量付费余额扣费。请确保余额充足并注意监控，避免服务中断或意外费用。如需更换备用 Key，点击 **Reselect** 重新选择即可。
:::

## 在 Studio Chat 中使用订阅制

除了通过 API Key 在开发工具中使用，你还可以在 **[ZenMux Studio Chat](https://zenmux.ai/chat)** 网页端直接使用订阅配额对话。

<img src="https://cdn.marmot-cloud.com/storage/zenmux/2026/02/03/l48igiH/studio-chat-mode.png" alt="Studio Chat 计费模式切换" >

在对话设置的 **Billing Mode（计费模式）** 中可以选择：

- **Subscription（订阅制）** — 使用订阅配额（Flows），不消耗账户余额
- **Pay As You Go（按量付费）** — 从账户余额按实际使用量扣费

::: tip 灵活切换
两种模式可随时切换、互不影响。例如：日常开发、学习、原型验证使用 Subscription；生产环境测试、商业化项目验证使用 Pay As You Go。
:::

::: warning 配额共享
Studio Chat 与 API 调用**共用同一个订阅配额池**。在 Studio Chat 中的对话同样会消耗订阅 Flows，请合理分配使用。
:::

## 升级与降级 {#upgrades-and-downgrades}

订阅期间可随时切换套餐：

- **升级**（如 Starter → Max）**立即生效**，按当前计费周期的剩余时长收取差价
- **降级**在当前周期结束后生效，不产生额外费用

### 升级差价计算（按剩余周期 Proration）

升级时只支付「本周期剩余时间对应的价差」，而非整月差价。

| 符号    | 含义                                |
| ------- | ----------------------------------- |
| `P_old` | 当前套餐月费（USD）                 |
| `P_new` | 目标套餐月费（USD）                 |
| `T`     | 当前计费周期总时长（通常 = 1 个月） |
| `T_rem` | 距离本周期结束的剩余时长            |
| `Δ`     | 升级需补齐的差价                    |

```text
Δ = max(0, (P_new − P_old) × (T_rem / T))
```

即：**差价 = 套餐价差 × 剩余周期占比**。若 `P_new ≤ P_old`（不构成升级），差价取 0。

**示例** — Starter（$20/月）升级到 Max（$100/月），本周期还剩 15 天（周期共 30 天）：

```text
Δ = (100 − 20) × (15 / 30) = 80 × 0.5 = $40
```

升级时仅需补差价 **$40**；新周期重置后恢复 Max 的正常月费 $100。

::: tip 计费周期保持一致
升级后原有计费周期**不会重置**——下次续费日期仍与升级前相同，避免「升级即续费」导致的双重扣费。
:::

## 常见问题

### 订阅制和按量付费有什么区别?

| 特性             | 订阅制 (Builder Plan) | 按量付费 (Pay As You Go) |
| ---------------- | --------------------- | ------------------------ |
| **计费方式**     | 固定月费              | 按实际使用量计费         |
| **适用场景**     | 个人开发、学习        | 生产环境、商业应用       |
| **费用可预测性** | 高（固定月费）        | 中（随用量波动）         |
| **速率限制**     | 10–15 RPM             | 更高，支持自定义         |
| **SLA 保障**     | 标准                  | 更高                     |
| **价值杠杆**     | 1.50–2.40 倍          | 标准 API 定价            |

### 什么时候配额会重置?

两个窗口均为滚动机制：

- **5 小时窗口** — 从发出第一个请求开始计时，每 5 小时重置
- **周限额** — 从发出第一个请求开始计时，每满 7 天重置

可在 [订阅管理页面](https://zenmux.ai/platform/subscription) 实时查看剩余配额与重置时间。

### 可以升级或降级套餐吗?

可以，随时在控制台操作。**升级立即生效**（按剩余周期补差价），**降级在当前计费周期结束后生效**。详见 [升级与降级](#upgrades-and-downgrades)。

### 订阅制可以用于生产环境吗?

不可以。订阅制仅面向个人开发、学习与 Vibe Coding 等非生产场景。生产环境请使用 [按量付费](./pay-as-you-go)，以获得更好的 SLA、稳定性与扩展能力。

### Studio Chat 和 API 共用配额吗?

是的。Studio Chat 网页端与 API 调用共用同一个订阅配额池，请合理分配用量。

### 支持哪些支付方式?

支持 Stripe 信用卡与支付宝（Alipay）。

### 可以同时使用多个套餐吗?

不可以。一个账号只能同时激活一个订阅套餐。如需更高额度，请升级到 Max 或 Ultra。

### 某个模型是否包含在我的套餐中?

请前往 [订阅定价页](https://zenmux.ai/pricing/subscription)，在对应套餐卡片点击 **View**，在弹窗中搜索该模型名称即可确认。详细步骤见 [查看套餐支持的模型](#supported-models)。
