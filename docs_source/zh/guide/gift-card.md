# 礼品卡指南

**Gift Center** 用于购买、分享和兑换 ZenMux 礼品卡。礼品卡兑换后会转为收礼人的 **PAYG Credits**，不支持兑换订阅。

::: info 仅支持个人账户
Gift Center 目前仅对个人账户开放。如果当前处于组织账户，请先切换到个人账户。
:::

## 购买礼品卡

1. 登录 ZenMux，进入 **Gift Center**。
2. 点击 **Buy Gift Card**。
3. 选择预设金额，或输入 **$5–$500** 的整数自定义金额。
4. 选择卡面和支付方式；收件人邮箱、留言均可稍后分享时再填写。
5. 完成支付，等待礼品卡生成。

::: tip 购买限额
默认情况下，每个账户每天最多购买 10 张、累计金额不超过 $1,000；实际限制以购买页面显示为准。
:::

## 分享礼品卡

在 **Purchased** 列表中找到可用礼品卡，点击 **Share**，可选择：

- 发送到收件人邮箱；
- 保存为图片；
- 复制兑换链接。

发送前请确认收件邮箱：

| 收件人状态        | 绑定与兑换规则                                               |
| ----------------- | ------------------------------------------------------------ |
| **已注册 ZenMux** | 礼品卡会绑定该 ZenMux 账户，只能由该账户兑换，发送后不可退款 |
| **未注册 ZenMux** | 礼品卡不会绑定账户，任何获得图片、链接或卡码的人都可能兑换   |

::: warning 请通过可信渠道分享
每张礼品卡只能兑换一次，请勿公开卡码或兑换链接。
:::

## 兑换礼品卡

1. 登录要接收 Credits 的 ZenMux 个人账户。
2. 进入 **Gift Center**，点击 **Redeem**。
3. 输入 `ZMGC-XXXX-XXXX-XXXX` 格式的卡码并确认。
4. 兑换成功后，金额会立即计入当前账户的 PAYG Credits。

也可以直接打开赠送人提供的兑换链接。系统会预填卡码，但仍需手动确认兑换。

兑换链接格式：

```text
https://zenmux.ai/platform/redeem?code=ZMGC-XXXX-XXXX-XXXX
```

其中 `ZMGC-XXXX-XXXX-XXXX` 替换为完整礼品卡卡码。示例：

```text
https://zenmux.ai/platform/redeem?code=ZMGC-8K2M-P4QW-N7XR
```

::: warning 兑换失败怎么办
如果连续多次输入无效卡码，兑换功能会被临时锁定。遇到"已兑换""已退款"或"收件人不匹配"等提示时，请先与赠送人核对卡片状态和收件邮箱。
:::

## 查看记录与退款

| 页签             | 用途                             |
| ---------------- | -------------------------------- |
| **Purchased**    | 查看自己购买的礼品卡及其状态     |
| **Received**     | 查看收到的礼品卡，并兑换可用卡片 |
| **Transactions** | 查看购买支出、兑换入账和退款状态 |

只有购买人自留、尚未分享或兑换且仍在退款期限内的礼品卡可以申请退款。默认退款期限为购买后 24 小时，退款会扣除 5% 手续费并原路退回；最终资格、金额和进度以页面显示为准。

## 常见问题

### 兑换后可以转给别人吗？

不可以。礼品卡兑换后会直接变成当前账户的 PAYG Credits。

### 礼品卡可以兑换订阅吗？

不可以，目前仅可兑换为 PAYG Credits。

### 支付成功后没有立即看到礼品卡怎么办？

支付确认可能需要短暂处理。请稍后刷新 Gift Center，并在 **Transactions** 中查看状态；如果长时间未更新，请联系 ZenMux 支持并提供交易时间和订单信息，请勿发送完整卡码。
